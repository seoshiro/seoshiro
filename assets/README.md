# Profile assets · 5 November 2026

The light/dark covers and avatar are local Cycles renders of the approved five-petal LOTUS model from [the portfolio](https://github.com/seoshiro/seoshiro.github.io/blob/main/art/soft-lotus/soft-lotus-editable.blend), not a newly generated flower. No purchase or generation credits were used. The ivory petal material is retained in both themes. Typography uses the portfolio’s Manrope and Cormorant Garamond fonts (SIL OFL), rasterized into the covers; important text and links are repeated in native Markdown.

`scripts/render-profile.py` renders at 1600 × 680 (covers) and 1024 × 1024 (avatar). It expects the existing portfolio Blender file and fonts under a local `source/` directory. Those source files remain in the portfolio repository; they are not duplicated here.
